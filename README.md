# CampusCode
 Campus Code is an online platform for students that combines programming studies, coding challenges, and a competitive format.

1) **Про платформу**

Користувачі можуть розв’язувати задачі з програмування, писати та перевіряти власний код, прокачувати свій профіль і рейтинг та змагатися в різних форматах

2) **Функціонал**

Профіль

Кожен користувач має власний профіль із:

* рівнем, досвідом та рангом;
* статистикою розв’язаних задач;
* досягненнями;
* історією змагань;
* інформацією про команду.

3) **Задачі з програмування**

Задачі поділяються за складністю: **легкі / середні / складні**.

Користувач пише код у вбудованому редакторі та надсилає його на перевірку. Код запускається через **Judge0** та перевіряється на тестових даних.

Результат:

* правильне рішення;
* неправильна відповідь;
* помилка компіляції;
* помилка під час виконання.

За правильне рішення користувач отримує **досвід**.

4) **Режими**

* **Одиночний режим** — самостійне розв’язання задач і розвиток профілю.
* **Змагання один на один** — змагання двох користувачів на швидкість і правильність.
* **Командний режим** — командні змагання.

5) **Команди**

Користувачі можуть створювати або вступати в команди.

Команда має **капітана, основний склад до 5 гравців і загалом до 20 учасників**, а також власні рейтинг, рівень, нагороди та історію змагань.

6) **Таблиці лідерів**

Окремі рейтинги для:

* учасників;
* команд;
* турнірів.

7) **Загальна механіка**

Задачі → досвід → рівень і ранг → змагання один на один або командні змагання → турніри → нагороди та рейтинг → розвиток профілю й команди.
